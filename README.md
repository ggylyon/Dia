# 🚀 Dia — Creative Agency Landing Page

**Dia** is a modern, responsive landing page for a creative digital agency. The website showcases the agency's expertise, services, client testimonials, and contact information through a clean and visually engaging interface.

The project focuses on responsive web design, smooth navigation, interactive elements, and a well-structured layout to provide a seamless browsing experience across different devices.

## 🌐 Live Preview

**[View Live Demo](https://ggylyon.github.io/Dia)**

## 🛠 Technologies Used

- **HTML5** — semantic structure and accessible markup.
- **SCSS (Sass)** — modular styling, variables, and reusable styles.
- **CSS3** — responsive layouts, animations, and visual effects.
- **JavaScript (ES6+)** — interactive elements and dynamic functionality.
- **BEM Methodology** — organized and maintainable CSS class naming.
- **Parcel** — development server and project bundling.
- **npm** — dependency management and development scripts.

## ✨ Features

- 📱 **Responsive Design** — layouts designed for desktop, tablet, and mobile screens.
- 🎨 **Modern UI** — clean typography, vibrant accents, and visually appealing sections.
- 🧭 **Smooth Navigation** — animated scrolling between website sections.
- 🖼️ **Interactive Image Slider** — switch between images in the hero section.
- 💼 **Services Showcase** — structured cards highlighting the agency's services.
- ⭐ **Client Testimonials** — dedicated section featuring customer feedback.
- 📩 **Contact Form** — form fields with built-in HTML validation.
- 🔗 **Social Media Links** — quick access to social platforms.

## 📑 Website Sections

The landing page consists of several sections:

1. **Hero** — introduction to the agency with an interactive image slider.
2. **About Us** — information about the agency's vision and approach.
3. **Our Expertise** — branding, communication, and strategy.
4. **Services** — overview of the agency's creative and digital services.
5. **Testimonials** — client reviews and feedback.
6. **Contact Us** — contact form, location, and social media links.

## ⚙️ Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/) (LTS version recommended)
- npm
- Git

### Installation

**1. Clone the repository:**

```bash
git clone https://github.com/ggylyon/Dia.git
```

**2. Navigate to the project directory:**

```bash
cd Dia
```

**3. Install dependencies:**

```bash
npm install
```

**4. Start the development server:**

```bash
npm start
```

**5. Open the local URL displayed in your terminal.**

### Production Build

To create an optimized production build:

```bash
npm run build
```

### Code Quality

To run the project's linting checks:

```bash
npm run lint
```
